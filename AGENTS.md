# Project continuity

Use this directory as the working root for the contour-processing project. Run model notebooks and tests from this root. Both model notebooks share the implementation here. Keep generated results under `outputs/` in the appropriate experiment subfolder.

When project work changes, update [PROGRESS.md](PROGRESS.md) under its Pacific calendar date. Extend the existing section if that date is already present. Record the researcher's requests, completed work, points that needed a plain-language explanation, new ideas or questions from the researcher, and clarifications from the assistant. Link relevant figures, diagrams or run results. Distinguish proposed experiments from completed runs and identify categories with no new discussion.
